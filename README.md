# Portfólio — Raquel Balduino

React + Vite + Tailwind CSS 4 + Motion.

## Rodar

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera a pasta dist/
```

## Onde editar

- `src/data/site.js` — nome, frase, links e e-mail
- `src/data/art.js` — imagens laterais de composição
- `src/styles/index.css` — cores e fontes (bloco `@theme`)
- `public/images/` — imagens do site
